## 2026-08-26 - MongoDB Aggregation for Multi-Generation Referral Stats
**Learning:** Sequential `countDocuments` calls for each referral generation (gen1 through gen6) cause 6 individual database round-trips per user stat request. Mongoose does not automatically convert string IDs to `ObjectId`s in aggregation pipelines, so explicit `ObjectId` casting is required for `$match` filters. Combining `countDocuments` queries into a single `$group` aggregation pipeline with a compound index `{ reffer: 1, gen: 1 }` reduces DB queries from 6 to 1 and allows index-backed aggregation scans.
**Action:** When calculating grouped counts across fixed enum or numeric properties (e.g. generations or statuses), use a single `$group` aggregation with a compound index instead of multiple `countDocuments` calls.
